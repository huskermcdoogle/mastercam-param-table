    Copy from op

    Ribbon: Parameter Table tab › Edit cells › Copy from op

    What this is for

    Makes ops match. You pick the columns (by selecting cells in them), pick the op to copy from, and the values go into the other ops you selected – or into every op that uses the same tool.

    When to use it

    • One op runs well. You want the same feed and speed on a similar op.
    • You tuned one op of a tool and want all of that tool's ops the same.

    Steps

    1. Click the op to copy from – in a column to copy – so the cursor is on it.
    2. Select the cells to copy (for example feed and speed). Hold Ctrl to add the same cells in the rows to copy into.
    3. Click Copy from op.
    4. Copy from: starts on the op the cursor is on. Pick another in the list if you like (it shows each op's number, type and comment).
    5. Into: The selected rows, or Every other op of tool ... (every op with the same tool as the op you copy from).
    6. Read the preview: how many cells change, and each cell, old → new.
    7. Click OK. Ctrl+Z takes it back.

    Units are checked. A feed is not copied into a row whose feed is in other units (per rev / per min), and a speed not into a row with the other of CSS / RPM – those cells are refused and listed. Copy the unit column too (feed_mode, speed_mode) and they go across together. A feed of 0.012 per minute would be a crawl.

    Worked example

    Op 7 (Rough Bore ID) now runs well at 0.012 per rev and 220 SFM. Make op 8 (Finish Bore ID, same tool T12) the same.

    1. Click op 7's feed cell, drag across to its speed cell. Hold Ctrl and do the same on op 8.
    2. Click Copy from op. Copy from shows op 7, Into shows The selected rows: op 8. The window says 2 cell(s) will change.
    3. Click OK.
    op 8BeforeAfter
    feed0.010.012
    speed200220
    feed_mode, speed_modeper rev, CSSper rev, CSS (same – no warning)

    A finish pass often wants a lighter feed than the rough. Copy what makes sense, not everything.

    What the messages mean

    Pick the op to copy from.
    No source op is picked yet.
    The selected rows - none besides op 7 (select the rows to copy into)
    Only the source op is selected. Hold Ctrl and add cells in the rows to copy into, or pick Every other op of tool ....
    No other op uses this tool - pick the selected rows, or select some.
    Every other op of tool found only the op you copy from.
    ... not copied - the units differ (per rev / per min, CSS / RPM); listed below
    See the box above: copy the unit column too.
    ... refused (read-only, not for that operation, or outside its limits)
    That column does not exist for the target's kind of op, or the value is past its limits.
