    Copy from op

    Ribbon: Parameter Table tab › Edit cells › Copy from op

    What this is for

    Makes ops match. You pick the columns (by selecting cells in them), pick the op to copy from, and the values go into the other ops you selected – or into every op that uses the same tool.

    When to use it

    • One op runs well. You want the same feed and speed on a similar op.
    • You tuned one op of a tool and want all of that tool's ops the same.

    Steps

    1. Select cells in the columns to copy (for example feed and speed), in the rows of the ops to copy into.
    2. Click Copy from op.
    3. Pick the op to copy from in the list (it shows each op's number, type and comment).
    4. Pick where it goes: the ops you selected, or every op of the tool.
    5. Read the preview: each cell, old → new, and any warning.
    6. Click OK.

    Watch the units. If the op you copy from runs per rev and the other runs per min (or one is CSS and the other RPM), the window warns you. Copy the feed_mode / speed_mode column too, or the number will mean something else. A feed of 0.012 per minute is a crawl.

    Worked example

    Op 7 (Rough Bore ID) now runs well at 0.012 per rev and 220 SFM. Make op 8 (Finish Bore ID, same tool T12) the same.

    1. Select op 8's feed and speed cells.
    2. Click Copy from op, pick op 7, click OK.
    op 8BeforeAfter
    feed0.010.012
    speed200220
    feed_mode, speed_modeper rev, CSSper rev, CSS (same – no warning)

    A finish pass often wants a lighter feed than the rough. Copy what makes sense, not everything.

    What the messages mean

    Pick the operation to copy from.
    No source op is picked yet.
    No other operation uses this tool.
    “Every op of the tool” found only the op you copy from.
    A warning that per rev / per min (or CSS / RPM) differ
    The source and the target count the feed (or speed) in different units. See the box above.
    ... refused (read-only, not for that operation, or outside its limits)
    That column does not exist for the target's kind of op, or the value is past its limits.
