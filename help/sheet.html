    The main sheet

    Workbook: the Lathe params sheet

    What this is for

    This is where you edit. Each row is one op, in the same order as Mastercam's Operation Manager. Row 1 has the group names (Feeds and speeds, Coolant ...). Row 2 has the column names (feed, speed ...). The first columns – op number, type, tool, comment – stay in view when you scroll right.

    When to use it

    Any time you change a setting. You can type straight into the cells, like any spreadsheet. The ribbon tools (Set, Scale ...) just make big changes quicker.

    Steps

    1. Find the op's row. Scroll, or use Find op on the ribbon.
    2. Find the column. Hover over a column name in row 2 to read what it is. A group that is folded away shows only one column: click the small + above the column letters to open it. (With macros: Go to on the ribbon opens a group for you.)
    3. Type the new value and press Enter. The cell turns yellow. Click a cell with a small arrow on its right to pick from a list (for example per rev / per min).
    4. Watch the row's numbers move: est_cycle_time, flips and MRR follow your edit. See How the estimate works.
    5. Save when you are done (Ctrl+S).

    Rules that keep you safe

    • An empty cell means “leave it alone” – never zero.
    • Each cell checks what you type. A value Mastercam would not take is refused straight away, with a message saying what the cell takes. Click Retry or Cancel.
    • Grey cells refuse typing. They are read-only (a time, a count) or the setting is not part of this kind of op.
    • A feed is two cells: the number (feed, always positive) and its unit (feed_mode: per rev or per min). A speed is the number (speed), CSS or RPM (speed_mode) and CW or CCW (spindle_dir).
    • Sorting and filtering are fine. The load finds each row by its op number, not by where it is.
    • X values are a radius in the travel columns (double them for diameter). A few angles are in radians – the tooltip says so.

    Worked example

    Op 17 (Multiple Plunge Groove) plunges at 0.0025 inch per rev. You want 0.003.

    1. Find op 17's row. Click its feed cell (Feeds and speeds group).
    2. Type 0.003, press Enter.
    op 17BeforeAfter
    feed0.00250.003
    feed_modeper revper rev
    changes01
    est_cycle_time0:09:00shorter (blue)

    If you had typed -0.003 by mistake, the cell would refuse it: a feed is never below 0 here.

    What the messages mean

    Excel: This value doesn't match the data validation restrictions ... (or the cell's own message)
    The value is outside what the setting takes. The message says what it takes, e.g. A number, 0 or more.
    The cell will not take any typing
    It is grey: read-only, or not for this kind of op. Its message says which.
    Status bar: op 7: CSS with no max_ss. or op 7: feed 0.01 per min is very slow - meant per rev?
    A gentle warning, not a refusal. CSS with no max RPM can spin very fast near the center. A per-minute feed of 0.01 is probably a per-rev number in the wrong mode (and a per-rev feed over 0.1 in is probably a per-minute one). Check the row.
