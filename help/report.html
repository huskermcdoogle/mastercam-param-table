    Change report

    Ribbon: Parameter Table tab › Undo and review › Change report

    What this is for

    A one-page report of what you changed and what it saves: cycle time per part and per batch, insert flips, and insert cost – before and after. Every change is listed, with a Why column for you to type the reason. Print it or save it as a PDF for the job folder, your lead, or the next programmer.

    When to use it

    • Before you load: to get a change signed off.
    • After you load: to keep a record of what changed and why.

    Steps

    1. Type the batch quantity on the Summary and the insert costs on the Tools page first – the report uses them.
    2. Click Change report. The Change report sheet opens, with the part's name and the date it was dumped at the top.
    3. Read Before -> after: cycle time and cutting time per part (and per batch), insert flips, inserts used and insert cost per part, and insert cost per batch – as dumped, now, and the change.
    4. Read Every change, by op: each op with its time change, then each parameter, as dumped and now.
    5. Type a short reason in the Why (type the reason) column (“insert box says 0.008-0.016”). Your reasons are kept when you make the report again.
    6. Print it: File › Print (or Ctrl+P). It is set up landscape, one page wide. Pick Microsoft Print to PDF to make a PDF.

    What the messages mean

    No changes from the dump yet - edit 'Lathe params' first.
    Nothing to report: the sheet is as dumped.
    Type the cost per insert on the Tools page for the insert cost per part and per batch.
    The cost lines are blank until you type the insert costs.
    The change report stopped: ...
    Something went wrong making it. Save your work and tell whoever looks after the tool what it said.
