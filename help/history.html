    History and the machine's time

    Workbook: the History sheet (the second tab) and From the machine on the Summary · File: <part>.pthistory beside the part

    What this is for

    The tool keeps a diary for each part. Every dump, load, undo and regeneration goes in it, with the cycle time, insert flips and insert cost before and after. You can add what a part really took on the machine, and the reason for each change.

    The diary is a small text file next to the part, called <part>.pthistory. Every dump shows it on the History sheet, newest first. The sheet adds up what the loads saved, per part and per batch. This is how you show a shop lead that a change really saved time and inserts.

    When to use it

    • After a load: to see what it saved, and the total so far.
    • After a run on the machine: type the real time per part, so the estimate gets checked.
    • When someone asks did that change help? – print the History sheet.

    Steps

    Type what the machine really did

    1. Run the part on the machine. Time one part, door closed to door open. Count the inserts the run used up, if you can.
    2. Open the newest workbook of the part. On the Summary page, find From the machine.
    3. Type the time for one part beside Actual cycle time per part: minutes:seconds (4:30) or hours:minutes:seconds (1:02:30). A time over 24 hours is fine (26:32:07).
    4. Type the Date it was measured (2026-10-12), the Parts run, the Inserts used (leave it blank if nobody counted) and a note if you like.
    5. Read the line under it: Machine against the estimate shows the difference and the percent. Slower means the machine took longer than the estimate.
    6. Save the workbook. The next dump or load copies it into the part's history. No macros are needed, and the workbook does not have to be loaded.

    Read the History sheet

    1. Dump the part (Dump to Excel). Click the History tab, next to Summary.
    2. Read So far at the top: the time saved per part and per batch, the inserts and their cost, the last time measured on the machine, and the last regeneration against Mastercam.
    3. Read the list under it, newest first. A load shows the cycle time before → after, the time Saved / part, Saved / batch (with the batch quantity) and Saved so far. The reasons typed in the Change report sit under their load.
    4. To print it: Ctrl+P. It is set up landscape, one page wide, with the headings on every page.

    An undo of a load takes that load's saving back off the total. A regeneration (see Regenerate) puts Mastercam's own cycle time beside the estimate.

    The history file

    <part>.pthistory is plain text. Open it with Notepad to read it. Each line is one thing that happened, oldest first. The tool only ever adds lines to the end:

    2026-10-10 11:02 | load | file: shaft_params_1.xlsx | changes: 14 | ops: 6 | cycle: 26:32:07 -> 25:10:40 | ...
2026-10-13 07:05 | actual | measured: 2026-10-12 | cycle: 25:40:00 | parts: 40 | inserts: 31 | estimate: 25:10:40

    Each measurement and each reason is kept once, however often the workbook is read. Delete the file to start a new history.

    Worked example

    A shaft was dumped at 26:32:07 a part. Batches are 40 parts. The History sheet shows (newest first):

    WhenWhat happenedCycle time / partSaved / partSaved / batchSaved so far
    2026-10-13Measured on the machine on 2026-10-12: 40 parts25:40:00
    2026-10-11 10:30Undid the last load: 2 values put back-0:10:00-6:40:00 (40)1:21:27
    2026-10-11 10:00Loaded 2 changes on 1 operation25:10:40 -> 25:00:400:10:006:40:00 (40)1:31:27
    2026-10-10 11:02Loaded 14 changes on 6 operations26:32:07 -> 25:10:401:21:2754:18:00 (40)1:21:27
    2026-10-10 09:14Dumped 42 operations (the whole part)26:32:07

    The first load saved 1:21:27 a part – 54 hours on a batch of 40. The second load was undone, so its 10 minutes come off the total again. On the machine a part took 25:40:00. That is 0:29:20 slower than the estimate of 25:10:40 (+1.9%), so the real saving is a little less than the estimate says. So far reads: 2 loads (1 undone). Time saved per part: 1:21:27 - 5.1% of the first dump's 26:32:07.

    What the messages mean

    Type the actual time above.
    Nothing is typed under From the machine yet, so there is nothing to compare.
    Excel says Type a time: minutes:seconds (4:30) or hours:minutes:seconds (1:02:30).
    The time is not written as a time. Type it with colons, like 4:30.
    Only some of the part's operations are on this sheet ...
    The workbook holds only some ops (a selection), so its estimate is not the whole part's. Dump all ops to compare with the machine.
    No loads yet. / Nothing measured on the machine yet ...
    The part has no load, or no measurement, in its history. Savings count from the first load.
    partly undone ... - its saving still counts
    An undo put back only some of that load's values (you unticked some, or some had changed since), so the load's saving is still in the total.
    history: could not write ... in ParamTable.log
    The folder of the part cannot be written to, or the history file is open in another program. Close it and try again.
