    Troubleshooting

    What this is for

    Something did not work, or a message came up. Find it below. Each topic page also has its own “What the messages mean”.

    When to use it

    When the tool does not do what you expect – before you give up on a change.

    Steps

    1. Read the message word for word. Type a few of its words into the search box at the top of this page.
    2. Look for it in the list below.
    3. Nothing went into the part yet? Then nothing is lost: Excel edits stay in the workbook until you load.
    4. Something went into the part and it is wrong? Run Lathe params - undo last load.

    Worked example

    Problem: the workbook opened, but there is no Parameter Table tab on Excel's ribbon.

    CheckWhat you seeFix
    The file name ends in.xlsxIt was dumped without macros. Dump again with Include macros ticked (you get an .xlsm).
    A yellow bar under the ribbonMacros have been disabledClick Enable Content.
    A red barMicrosoft has blocked macros ...The file came from email or the internet. Close it, right-click the file, Properties, tick Unblock, OK, open it again.
    A yellow barProtected ViewClick Enable Editing.

    Problems and messages

    In Mastercam

    The commands are not in Mastercam at all
    See Install: both ParamTable.ft and the ParamTable folder must be in the Add-Ins folder, and Mastercam must be restarted.
    Save the part first ...
    Save the part (File, Save). The dump and load work beside the saved part file.
    The dump failed unexpectedly. Nothing was changed in the part.
    Something in the part upset the tool. Try dumping fewer ops to find which one, and tell whoever looks after the tool.
    The load failed unexpectedly. Check ParamTable.log ...
    The load stopped part way. ParamTable.log beside the part lists which ops were written. Run undo last load to put them back.
    ... could not be opened (is it still open in Excel?)
    Save in Excel first. If it still fails, close the workbook in Excel and load again.
    The load found no changes
    The workbook was not saved after the edits, or you picked an older file. Save, and pick the right file (the load starts on the one you dumped last).
    Refused rows in the load preview
    See Load: what the messages mean.
    The NC code still has the old feed
    The changed ops need regenerating (they are marked dirty). Regenerate, then post again.

    In Excel

    No Parameter Table tab
    See the worked example above.
    A cell will not take what I type
    The value is outside what the setting takes, or the cell is grey (read-only, or not for this kind of op). The message says which. See The main sheet.
    The cycle time did not change when I changed a depth
    Depths change the toolpath itself; the estimate can only follow feeds and speeds. See How the estimate works.
    Times or flips are blank, or needs_regen says yes
    The op needed regenerating when it was dumped. Regenerate in Mastercam and dump again.
    Flips per part look wrong
    See How insert flips are counted. Check the inspection comment and the edge life on the Tools page.
    Insert cost is blank
    Type the edges and the cost per insert in the inserts table.
    Select cells on the 'Lathe params' sheet first.
    Click the Lathe params tab and select cells in the op rows.
    Something went wrong: ...
    A ribbon command hit an error. Press Undo on the ribbon to take back anything it did, save your work, and tell whoever looks after the tool what the message said.
    The user manual is not installed ...
    The help folder is not beside the add-in. Copy the whole ParamTable folder from the zip again.
    I lost my edits
    Only if the workbook was closed without saving. Edits you saved are in the file; a saved scenario is too.
