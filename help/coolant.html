    Coolant

    Ribbon: Parameter Table tab › Selected ops › Coolant

    What this is for

    Shows the coolant of the ops you selected and sets it for all of them at once. It works for both ways a Mastercam machine can be set up for coolant:

    • One setting per op (“V9” coolant): Off, Flood, Mist or Thru-tool. Column coolant.
    • Before / with / after the move (“X-style” coolant), using your machine's own coolant names. Columns coolant_before, coolant_with, coolant_after. Each can hold more than one coolant.

    Each op follows its own machine, so one part can have both kinds.

    When to use it

    • A program came over with coolant off on cutting ops.
    • You want thru-tool on all the drills, or mist instead of flood on a whole group.

    Steps

    1. Select the ops – any cell in their rows.
    2. Click Coolant. The sheet jumps to the coolant columns, so you see what is set now.
    3. Read the current setting. If the ops differ, it says how, e.g. Mixed: Flood x3, Off x1.
    4. Pick the coolant. One setting: pick Off, Flood, Mist or Thru-tool. Before / with / after: tick the coolants for each.
    5. Click Apply. Every op gets it. Ops that could not be set are listed, with the reason.

    The window stays open and follows the ops you click. Ctrl+Z takes back the whole Apply.

    Worked example

    On the Oil Spool Head, the prime turning ops (2, 3, 4, 5, 6) run with coolant Off. The others run Flood. You want flood on the two roughs, ops 2 and 3.

    1. Select a cell in op 2's row and op 3's row.
    2. Click Coolant. It says Off (both the same).
    3. Pick Flood, click Apply.
    Opcoolant beforecoolant after
    2 Prime Turn Rough ODOffFlood
    3 Prime Turn Rest Rough ODOffFlood

    Coolant does not change the cycle time estimate. It is listed in the load preview like any other change.

    What the messages mean

    Mixed: Flood x3, Off x1
    Three of the selected ops have Flood and one has Off. Applying sets them all the same.
    An op listed as not set: this machine has no ...
    That op's machine does not have that coolant. Each machine has its own list.
    An op listed as not set: no coolant
    Some ops have no coolant setting at all (a transform, a manual entry).
