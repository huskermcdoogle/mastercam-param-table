    Install the add-in

    A file copy. No installer, no admin rights.

    What this is for

    The tool is a Mastercam 2026 add-in. Installing it puts four commands into Mastercam: Lathe params - dump to Excel, Lathe params - load, Lathe params - undo last load and Parameter Table - user manual. This manual comes with it.

    When to use it

    Once per computer, and again when a new version comes out. Ask your CAD/CAM lead or IT if you are not allowed to add programs – some shops want to look at add-ins first.

    Steps

    1. Download the release .zip file and unzip it (right-click it, Extract All). Inside are ParamTable.ft and a folder called ParamTable.
    2. Close Mastercam. It only looks for add-ins when it starts.
    3. Open the folder Documents\My Mastercam 2026\Mastercam\Add-Ins.
    4. Copy ParamTable.ft and the ParamTable folder into it. You need both.
    5. Start Mastercam. A Parameter Table tab is on the ribbon with the four commands: dump to Excel, load, undo the last load, and this user manual. Nothing to set up.

    Want them somewhere else? The commands are also in Mastercam's Customize list, in the category Parameter Table Tool - put them on a tab of your own or on the Quick Access Toolbar. If you put them on a tab of your own, Mastercam shows yours and does not add the Parameter Table tab as well.

    Macros in Excel. If you tick Include macros when you dump, Excel may show a yellow bar: Macros have been disabled. Click Enable Content on that bar to get the Parameter Table tab. The workbook works without macros too – you just do not get the extra tools.

    After Mastercam starts, the ribbon has a Parameter Table tab with four buttons.

    What the messages mean

    There is no Parameter Table tab.
    Mastercam was open when you copied, or ParamTable.ft is not in the Add-Ins folder itself (it must not be inside the ParamTable folder). Fix it and restart Mastercam. If you already put the commands on a tab of your own with Customize, that tab is the one you get. Still nothing? The file ParamTable-ribbon.log in Add-Ins\ParamTable says what happened at start-up - send it to whoever looks after the add-in.
    The user manual is not installed.
    The help folder is missing from Add-Ins\ParamTable. Copy the whole ParamTable folder again from the zip.
