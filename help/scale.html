    Scale %

    Ribbon: Parameter Table tab › Edit cells › Scale %

    What this is for

    Makes every selected number bigger or smaller by the same percent – like turning the feed override knob, but saved in the program. Each cell keeps its own value: 0.010 and 0.020 at +10% become 0.011 and 0.022.

    When to use it

    • “These ops can all go 10% faster.”
    • “Back the speeds off 15% on this tough material.”

    To reach a set cycle time instead, use Hit a target time.

    Steps

    1. Select the number cells to change (e.g. the feed of several ops). Text cells and worked-out cells are skipped.
    2. Click Scale %.
    3. Type the change, with its sign: +10% means 10% more, -10% means 10% less. (Or pick one from the list.) A bare 10% is refused – the window asks which way.
    4. Read the preview: how many cells change, and each cell, old → new. Cells that would go past their limits are refused and listed.
    5. Click OK. Ctrl+Z takes it back.

    Worked example

    Raise the feeds of the facing op and the two bore ops by 10%. Select the feed cells of ops 1, 7 and 8 (hold Ctrl), click Scale %, type +10%, click OK.

    Opfeed before+10%
    1 Face Stock0.010.011
    7 Rough Bore ID0.010.011
    8 Finish Bore ID0.010.011

    The estimate on each row drops by about 9% of its cutting time (time goes down as feed goes up: 1 ÷ 1.10 = 0.91).

    What the messages mean

    10% more: 3 cell(s) will change.
    What OK will do. The list below shows each cell, old → new.
    '10%' - say which way: +10% for more, -10% for less.
    Type the sign.
    Type +10% for 10% more, or -10% for 10% less. / ... is not a percent - type +10% or -10%.
    The box is empty, or not a percent.
    -100% would leave nothing - type a smaller cut, such as -10%.
    A cut of 100% or more would make the values zero.
    ... refused (read-only, not for that operation, or outside its limits)
    The new value would be past what the setting takes. Those cells are left as they are.
