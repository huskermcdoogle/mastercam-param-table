    Comments & text

    Ribbon: Parameter Table tab › Selected ops › Comments & text

    What this is for

    A roomy window for the three kinds of text an op has:

    • Op comment – the name the Operation Manager shows (comment, up to 119 characters).
    • Inspection comment – the message at a tool inspection stop (insp_comment), e.g. ROTATE INSERT.
    • Manual text – the text of a manual entry op (manual_text, up to 3111 characters). Only for manual entry ops.

    It counts the characters as you type, against each one's limit. With several ops selected, it sets the same comment on all of them.

    When to use it

    • To rename ops so the setup sheet and the operator make sense of them.
    • To tell the operator what to do at an inspection stop (rotate the insert, check a size).
    • To edit a long manual entry without squinting at a cell.

    Steps

    1. Select the ops – any cell in their rows. (Or just double-click a comment, insp_comment or manual_text cell.)
    2. Click Comments & text. The sheet jumps to the comment columns so you can see what is there now.
    3. Pick the tab: Op comment, Inspection comment or Manual text.
    4. Type the text. The count under the box shows how many characters you have left. If the ops have different text, the box says so (Mixed).
    5. For an inspection comment, you can click a quick pick: ROTATE INSERT, CHANGE INSERT, INDEX INSERT, CHECK INSERT.
    6. Click Apply. The cells turn yellow. Ctrl+Z takes the whole Apply back.

    The window stays open beside the sheet. Click other ops and it follows them (unless you have typed something you have not applied yet). The ? button opens this page.

    The words in an inspection comment matter. A stop whose comment says ROTATE, FLIP, CHANGE or INDEX is counted as an insert flip – a new edge. CHECK INSERT is only a look, not a flip. Change CHECK INSERT to ROTATE INSERT and the flips per part go up.

    Worked example

    Say your rough bore and finish bore (ops 7 and 8, tool T12) stop for inspection with the comment CHECK INSERT. In your shop the operator always turns the insert at that stop. Say so in the comment, and the flips will be counted.

    1. Click a cell in op 7's row, hold Ctrl, click a cell in op 8's row.
    2. Click Comments & text, then the Inspection comment tab.
    3. Click ROTATE INSERT, then Apply.

    After you load and regenerate, the NC code carries the message at each stop. If the comment switch (insp_comment_on) is off, turn it on too.

    What the messages mean

    ... over the limit by 12
    Too long. Shorten it – the load refuses text that would be cut off.
    The Manual text tab is greyed out
    None of the selected ops is a manual entry op.
    Mixed
    The selected ops have different text. Whatever you type replaces all of them.
